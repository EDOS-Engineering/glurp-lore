# Contributing to the Lore

Fan lore is welcome. Pull up a stool.

## What we would love

- New short stories about Glurp, cousin Glorp, the valley, the tower, or the Discord regulars.
- New Glurp-isms for [quotes.md](quotes.md) and new terms for [glossary.md](glossary.md).
- Fixes for typos, broken links, or lines that do not scan (except the last line of the epilogue, which does not scan on purpose).

## House rules

1. **Keep it kind.** Glurp is warm and a bit bewildered, never cruel. Jokes punch at situations (loops, logs, cold caches), not at people or companies.
2. **Keep it all-ages.** No violence beyond mild tower fires, no crude language.
3. **Keep it original.** Do not borrow orks, characters, factions, catchphrases or slang from any existing game, book or film. Glurp's world is its own.
4. **Keep it fictional.** Do not name or portray real people. Real tools (such as Claude Code or Codex) may appear as tools Glurp uses, described respectfully, with no invented quotes attributed to real companies.
5. **Keep Glurp's pronouns.** Glurp uses they/them/their/themself, and has no gender.
6. **Keep Glurp's look.** Green skin, big lower tusks, one heavy brow, yellow eyes, purple hoodie with gold drawstring tips, brown boots. Orkestera orks wear indigo skin and teal.

## How to contribute

1. Fork the repository.
2. Add or edit Markdown files. New stories go in `chapters/` (or a `fan/` folder for side stories).
3. Open a pull request with a short description of what you added.
